Zilliz created an open-source alternative to Anthropic's Claude Tag, called Open Tag, built on MFS (Multi-source File-like Search). This system enables developers using Claude Code or Codex to mention a bot in Slack, which then searches across connected data sources like GitHub, databases, and documentation to provide contextual assistance.
